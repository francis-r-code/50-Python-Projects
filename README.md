# 💻 50 Python Projects

**Objective:** Complete at least one small Python project a week until 50 projects are completed total.

**Progress: 2/50 Completed**

This is a project I have decided to take upon to grow my Python programming skills in order to become a competent AI/ML engineer. By completing this project, I aim to grow my problem-solving and programming skills without relying on AI to do the work for me.

## 📁 Structure
Each project will be numbered and contained in its own folder, containing:
* A GIF demo
* A README summary of the project
* My solution Python file
  * *Each file was made with Python 3.15. To run them, ensure you have Python installed and open the file either via file explorer or a terminal.*

## 🚫 Project Rules

1. **No AI:** AI is not allowed for use in **any** aspect of the project. *Examples: generating code or performing research.*
2. **Manual Researching:** Research for the project must be done manually without the use of AI sources like Gemini or ChatGPT, and research should only be to gain information or to learn about programming syntax, not to find solutions to the problem.
3. **Consistency**: At least one project must be completed once a week to ensure Python skills stay fresh while allowing for flexibility with school and other events.
