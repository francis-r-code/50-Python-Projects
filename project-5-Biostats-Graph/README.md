# Biostats Grapher


A program written in Python to understand Pandas, CSV files, and matplotlib (Sample CSV file obtained at https://people.sc.fsu.edu/~jburkardt/data/csv/biostats.csv).

To see how I coded the program, check out the [coding session's YouTube video!](https://youtu.be/QcUENsiZev8)

## 🎯 Objective
Create a program that allows users to:
* Read a CSV file.
* Graph and compare data from the file.

## 🔧 Challenges and Learnings
* **Pandas:** To read the CSV file, I used pandas to create a dataframe that I could better work with. I learned how to select rows and columns, clean up missing data, and calculate statistics such as median, mean, and IQR. Learning the syntax and commands for pandas was a big challenge for me, and I had a hard time learning how to select and filter data.
* **Matplotlib:** This module lets me graph the dataframe created with the CSV file I had. Using my existing knowledge of Matplotlib, I learned how to create three graphs in one image and work with histograms.
